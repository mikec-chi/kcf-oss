# incoming/ — field-report drop folder

Write one field report per file here (`<id>.md`), each containing a single fenced
`kcf-field-report:v1` envelope. See [`../README.md`](../README.md) for the protocol and
[`../TEMPLATE.md`](../TEMPLATE.md) for the format.

- **Humans**: add your file and open a PR, or open a `field-report`-labeled issue instead.
- **Agents**: write the file(s) here; if you have repo/network access open the labeled
  PR/issue and return the URL, otherwise print the raw envelope(s) with submit
  instructions and hand off. Never claim a submission you didn't make.

Reports here are periodically triaged; accepted ones become issues/PRs and the file is
removed or archived. Nothing in this folder changes the grammar/IR/analyzer contract.
