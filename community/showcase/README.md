# Showcase — Built with KCF

Did you knowledge-code an app? Add it here. The showcase is social proof for the
project and a source of real examples for everyone else — especially when you link
the **model** you generated it from.

## Layout

One Markdown file per project, `kebab-case.md`:

```
community/showcase/acme-support-desk.md
```

Copy [`TEMPLATE.md`](TEMPLATE.md) to start. If the model is shareable, contribute it
to [`../models/`](../models/) too and link it — that's the most useful showcase of
all.

## The bar

- **Real** — a thing you actually built (shipped, prototype, or demo is fine).
- **Specific** — the domain, the stack, and what KCF did for you (not marketing).
- **Linkable** — a repo, a live URL, or screenshots where you can share them.

## What to include

Domain, stack (backend/frontend), the model (link if shared), what worked, what was
hard, and one honest lesson. See the template.
