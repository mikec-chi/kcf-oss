# 14 - Vertical-Slice Code Generation

> KCF stops at the semantic IR; code is generated by an LLM. For the standalone,
> tech-stack-parameterized pack (a durable system prompt + single-shot examples
> per stack — FastAPI, Express/Prisma, Django, React), see
> [`../../codegen/`](../../codegen/). This step is the workflow-integrated
> equivalent: the `ready` `model-ir.json` is the complete specification.

Run this prompt once for every capability identified in the application plan.

## Gate

Complete and test one semantic capability before beginning another.

## Prompt

```text
Implement the vertical slice for semantic capability [CAPABILITY_ID] in
[PROJECT_ROOT] using [TECH_STACK].

Read:

- domain/model-ir.json;
- domain/08-runtime-contract.json;
- domain/08-emitter-support.md;
- app/generation-plan.md;
- applicable profile models under app/models/.

The model-ir.json is your complete, machine-checked specification (it passed
`kcf assess` with `ready: true`). Realize only what it declares; never invent
missing behavior. Produce a coverage self-audit listing every construct you were
asked to realize as realized / delegated / out-of-tier / unsupported, with
`dropped: []` (see ../../codegen/system-prompt.md).

Generate only what this capability requires:

- domain and runtime types;
- persistence mapping and migrations;
- capability handler or use case;
- validation, invariants, and policy checks;
- authorization and data-scope enforcement;
- transaction, concurrency, idempotency, retry, and compensation behavior;
- API, command, query, or event interface;
- workflow/process integration;
- UI flow and states when selected;
- integration adapters;
- audit, evidence, lineage, and observability;
- unit, integration, contract, authorization, concurrency, and semantic tests;
- documentation and traceability metadata.

Requirements:

- annotate or map artifacts to source KCF semantic identities;
- reconcile generated files with the reference trace manifest and document
  deliberate replacements;
- preserve Action scope, selection, cardinality, effects, atomicity,
  concurrency, idempotency, authorization, and failure semantics;
- preserve classification, provenance, and lineage;
- do not implement behavior absent from the validated model;
- do not silently approximate unsupported semantics;
- run formatters, static checks, tests, and relevant application validation.

Produce a slice completion report listing generated files, semantic identities,
rule IDs tested, commands run, remaining risks, and gate status.

The phase passes only when the complete slice and its semantic tests pass.
```
